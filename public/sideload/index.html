1 免签名 · 立即使用（推荐先体验）

无需证书、无需电脑，iPhone 自带能力：把线上系统“装”到主屏幕，像 App 一样全屏运行。

  1. 用 iPhone 的 Safari 打开系统地址：https://furry233.cn/
  2. 点击底部「分享」按钮 ⌘
  3. 选择「添加到主屏幕」→ 确认添加
  4. 回到桌面，点击“买个Der”图标即可全屏使用
该方式与 Web 版共用账号体系与数据，彼此独立存在于桌面，互不影响；限制是纯在线运行（联网使用）。

2 真侧载 · IPA 电脑安装（Apple ID 即可）

把原生壳 App（独立应用，非网页）安装到 iPhone，适合长期使用与后续扩展离线/推送能力。

  1. 电脑下载上面的 PurchaseApproval.ipa（需先完成构建上传，见状态卡片）
  2. iPhone 连接电脑，使用 AltStore、Sideloadly 或 爱思助手 导入安装
  3. 首次需登录你的免费 Apple ID；免费签名每 7 天 需在电脑端重新导入一次
  4. 安装后进入「设置 → 通用 → VPN 与设备管理」信任开发者描述文件即可打开
仅需免费 Apple ID，无需开发者账号。数据与服务器完全互通（同一后端），登录态与 Web 版相互独立。

3 企业/开发者证书 · 无线安装

适合分发给多个 iPhone：点击链接即可 OTA 安装，无需电脑。

通过清单安装（itms-services）
暂不可用：无线安装要求 HTTPS 域名 + 企业/Ad Hoc 签名 的 .ipa。 当前服务器为 HTTP + IP 访问；请按指南 docs/ios-sideload.md 启用 HTTPS 并上传签名产物后重试。

关于本版本

  • 独立存在：拥有独立 App 标识 cn.purchaseapproval.sideload，与网页版、主屏图标互不覆盖，可同时共存。
  • 数据互通：所有版本都连接同一套后端与数据库（创建申请、投票审批、通知提醒实时一致）。
